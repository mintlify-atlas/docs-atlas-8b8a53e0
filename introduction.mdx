## What is YouTube Manager?

YouTube Manager is a comprehensive Django-based SaaS platform designed to simplify video content management for YouTube creators. It provides an intuitive interface to search YouTube videos, organize your content collections, and upload videos directly to your channel - all through a single, unified platform.

## Why YouTube Manager?

Managing YouTube content can be overwhelming, especially for creators juggling multiple videos, channels, and content ideas. YouTube Manager solves key challenges:

- **Centralized Search**: Search YouTube's entire catalog without leaving your workspace
- **Content Collections**: Save and organize videos for reference, inspiration, or curation
- **Direct Upload**: Upload videos to your YouTube channel with custom privacy settings
- **OAuth Integration**: Secure Google authentication with full YouTube API access
- **Personal Dashboard**: Manage your uploaded videos and modify their privacy status

## Technology Stack

YouTube Manager is built with modern, robust technologies:

- **Framework**: Django 6.0.1 - High-level Python web framework
- **Database**: MySQL with mysqlclient 2.2.7
- **Authentication**: Google OAuth 2.0 with google-auth-oauthlib 1.2.4
- **YouTube Integration**: google-api-python-client 2.188.0
- **Configuration**: python-decouple 3.8 for environment management
- **Python**: Requires Python 3.x

## Architecture Overview

YouTube Manager follows Django's Model-View-Template (MVT) architecture:

### Data Models

Two core models power the application:

- **VideoGuardado** (Saved Videos): Stores user's saved video collections with metadata
- **VideoSubido** (Uploaded Videos): Tracks videos uploaded through the platform

### Authentication Flow

1. Google OAuth 2.0 integration for secure user authentication
2. Credential storage in Django sessions for API access
3. Automatic user registration on first login
4. YouTube API access scopes:
   - `youtube` - Read/write access to YouTube data
   - `youtube.upload` - Upload videos
   - `userinfo.email` and `userinfo.profile` - User profile data

### API Integration

The platform leverages YouTube Data API v3 for:

- **Search**: Query YouTube's video catalog with filters
- **Upload**: Resumable uploads with metadata configuration
- **Management**: Update video privacy status and delete videos
