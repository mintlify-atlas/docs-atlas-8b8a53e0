## System Requirements

Before installing YouTube Manager, ensure your system meets these requirements:

- **Python**: 3.x or higher
- **Database**: MySQL 5.7+ or MariaDB 10.2+
- **Operating System**: Linux, macOS, or Windows
- **Google Account**: For OAuth authentication
- **YouTube Channel**: For upload functionality

## Installation Steps

<Steps>
  <Step title="Clone the Repository">
    Clone the YouTube Manager repository to your local machine:

    ```bash
    git clone <repository-url>
    cd youtube_project
    ```
  </Step>

  <Step title="Create Virtual Environment">
    Create and activate a Python virtual environment to isolate dependencies:

    ```bash
    # Create virtual environment
    python -m venv venv

    # Activate on Linux/macOS
    source venv/bin/activate

    # Activate on Windows
    venv\Scripts\activate
    ```

    <Note>
      Always activate your virtual environment before working with the project.
    </Note>
  </Step>

  <Step title="Install Dependencies">
    Install all required Python packages from requirements.txt:

    ```bash
    pip install -r requirements.txt
    ```

    This installs the complete technology stack including:
    - Django 6.0.1
    - google-api-python-client 2.188.0
    - google-auth-oauthlib 1.2.4
    - mysqlclient 2.2.7
    - python-decouple 3.8

    And all other dependencies for OAuth, API integration, and database connectivity.
  </Step>

  <Step title="Configure MySQL Database">
    Create a MySQL database for the application:

    ```sql
    CREATE DATABASE youtube_manager CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
    CREATE USER 'youtube_user'@'localhost' IDENTIFIED BY 'your_secure_password';
    GRANT ALL PRIVILEGES ON youtube_manager.* TO 'youtube_user'@'localhost';
    FLUSH PRIVILEGES;
    ```

    <Warning>
      Use a strong password for your database user in production environments.
    </Warning>
  </Step>

  <Step title="Set Up Environment Variables">
    Create a `.env` file in the project root directory with the following configuration:

    ```bash
    # Django Settings
    SECRET_KEY=your-secret-key-here-generate-a-long-random-string
    DEBUG=True
    ALLOWED_HOSTS=localhost,127.0.0.1

    # Database Configuration
    DB_NAME=youtube_manager
    DB_USER=youtube_user
    DB_PASS=your_secure_password
    DB_HOST=localhost
    DB_PORT=3306

    # Google OAuth
    GOOGLE_CALLBACK_URL=http://localhost:8000/oauth2callback
    ```

    <Note>
      Generate a secure SECRET_KEY using:
      ```bash
      python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
      ```
    </Note>

    <Warning>
      Never commit your `.env` file to version control. Add it to `.gitignore`.
    </Warning>
  </Step>

  <Step title="Configure Google OAuth">
    Set up Google OAuth credentials:

    1. Go to [Google Cloud Console](https://console.cloud.google.com/)
    2. Create a new project or select an existing one
    3. Enable YouTube Data API v3
    4. Create OAuth 2.0 credentials:
       - Application type: Web application
       - Authorized redirect URIs: `http://localhost:8000/oauth2callback`
    5. Download the credentials JSON file
    6. Save it as `client_secret.json` in your project root

    <Info>
      The application requires these OAuth scopes:
      - `https://www.googleapis.com/auth/youtube`
      - `https://www.googleapis.com/auth/youtube.upload`
      - `https://www.googleapis.com/auth/userinfo.email`
      - `https://www.googleapis.com/auth/userinfo.profile`
      - `openid`
    </Info>
  </Step>

  <Step title="Run Database Migrations">
    Create the database schema by running Django migrations:

    ```bash
    python manage.py migrate
    ```

    This creates tables for:
    - User authentication (Django's built-in User model)
    - VideoGuardado (saved video collections)
    - VideoSubido (uploaded videos tracking)
  </Step>

  <Step title="Create Superuser">
    Create an admin account to access Django's admin panel:

    ```bash
    python manage.py createsuperuser
    ```

    Follow the prompts to set username, email, and password.

    <Note>
      The admin panel is accessible at `http://localhost:8000/admin/` and provides direct database access for troubleshooting.
    </Note>
  </Step>

  <Step title="Create Media Directory">
    Create a directory for temporary video file storage during uploads:

    ```bash
    mkdir media
    ```

    The application automatically manages this directory for video upload processing.
  </Step>

  <Step title="Verify Installation">
    Test your installation by starting the development server:

    ```bash
    python manage.py runserver
    ```

    You should see output similar to:

    ```
    Starting development server at http://127.0.0.1:8000/
    Quit the server with CONTROL-C.
    ```

    Visit `http://localhost:8000` in your browser to access the login page.
  </Step>
</Steps>

## Configuration Options

### Language and Timezone

The application is configured for Spanish (Mexico) by default:

```python
LANGUAGE_CODE = 'es-MX'
TIME_ZONE = 'America/Hermosillo'
```

You can modify these in `youtube_project/settings.py` to match your locale.

### Database Charset

The MySQL connection uses UTF-8MB4 for full Unicode support:

```python
'OPTIONS': {
    'charset': 'utf8mb4',
    'init_command': "SET sql_mode='STRICT_TRANS_TABLES'",
}
```

### Media Storage

Uploaded videos are temporarily stored in the `media/` directory before YouTube upload:

```python
MEDIA_URL = '/media/'
MEDIA_ROOT = os.path.join(BASE_DIR, 'media')
```

## Troubleshooting

### MySQL Connection Errors

If you encounter connection issues:

1. Verify MySQL is running: `sudo systemctl status mysql`
2. Check credentials in `.env` file
3. Ensure the database exists: `mysql -u root -p -e "SHOW DATABASES;"`

### OAuth Errors

If Google authentication fails:

1. Verify `client_secret.json` exists in project root
2. Check redirect URI matches Google Console configuration
3. Ensure YouTube Data API v3 is enabled in Google Cloud Console

### Import Errors

If you see "Couldn't import Django":

1. Verify virtual environment is activated
2. Reinstall dependencies: `pip install -r requirements.txt`
3. Check Python version: `python --version`
