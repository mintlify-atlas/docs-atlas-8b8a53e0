## Technology Stack

YouTube Manager is built with modern, reliable technologies:

- **Backend**: Django 6.0.1 with Python
- **Database**: MySQL with full UTF-8 support
- **Authentication**: Google OAuth 2.0
- **API Integration**: YouTube Data API v3
- **Language**: Spanish (es-MX) localization

<Note>
This platform requires Google API credentials and a YouTube account to function. See the [Configuration](/configuration/google-oauth) section for setup instructions.
</Note>
