## 1. Security Configuration

### DEBUG Mode

<Warning>
**Critical**: Set `DEBUG = False` in production. Debug mode exposes sensitive information and security vulnerabilities.
</Warning>

In `settings.py:16`, DEBUG is controlled via environment variable:

```python settings.py
DEBUG = config('DEBUG')
```

Update your `.env` file:

```bash .env
DEBUG=False
```

### SECRET_KEY

Generate a new, cryptographically secure SECRET_KEY for production:

```bash
python -c 'from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())'
```

<Warning>
**Never** use the development SECRET_KEY in production. Generate a new one and store it securely in your `.env` file.
</Warning>

Update `.env`:

```bash .env
SECRET_KEY=your-new-production-secret-key-here
```

### ALLOWED_HOSTS

Configure allowed hosts in `settings.py:18`:

```python
ALLOWED_HOSTS = config('ALLOWED_HOSTS', cast=Csv())
```

Update `.env` with your production domains:

```bash .env
ALLOWED_HOSTS=yourdomain.com,www.yourdomain.com,your-server-ip
```

### Security Headers

Add these settings to `settings.py` for production:

```python settings.py
# HTTPS settings
SECURE_SSL_REDIRECT = True
SESSION_COOKIE_SECURE = True
CSRF_COOKIE_SECURE = True

# Security headers
SECURE_BROWSER_XSS_FILTER = True
SECURE_CONTENT_TYPE_NOSNIFF = True
X_FRAME_OPTIONS = 'DENY'

# HSTS (HTTP Strict Transport Security)
SECURE_HSTS_SECONDS = 31536000  # 1 year
SECURE_HSTS_INCLUDE_SUBDOMAINS = True
SECURE_HSTS_PRELOAD = True
```

### Remove Development OAuth Settings

<Warning>
**Remove** the following line from `settings.py:123` in production:

```python
os.environ['OAUTHLIB_INSECURE_TRANSPORT'] = '1'
```

This setting allows HTTP for OAuth, which is **insecure** in production. OAuth must use HTTPS.
</Warning>

## 2. Database Setup

### Install MySQL

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install mysql-server mysql-client libmysqlclient-dev

# Start MySQL
sudo systemctl start mysql
sudo systemctl enable mysql
```

### Create Production Database

```bash
sudo mysql -u root -p
```

```sql
CREATE DATABASE youtube_manager_prod CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'youtube_user'@'localhost' IDENTIFIED BY 'secure-password-here';
GRANT ALL PRIVILEGES ON youtube_manager_prod.* TO 'youtube_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

### Configure Database Settings

Update `.env` with production database credentials:

```bash .env
DB_NAME=youtube_manager_prod
DB_USER=youtube_user
DB_PASS=secure-password-here
DB_HOST=localhost
DB_PORT=3306
```

### Production Database Optimizations

Add these options to `DATABASES` configuration in `settings.py`:

```python settings.py
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': config('DB_NAME'),
        'USER': config('DB_USER'),
        'PASSWORD': config('DB_PASS'),
        'HOST': config('DB_HOST'),
        'PORT': config('DB_PORT'),
        'OPTIONS': {
            'charset': 'utf8mb4',
            'init_command': "SET sql_mode='STRICT_TRANS_TABLES'",
            'connect_timeout': 10,
        },
        'CONN_MAX_AGE': 600,  # Connection pooling (10 minutes)
    }
}
```

### Run Migrations

```bash
python manage.py migrate
```

This creates tables for:
- `auth_user` - User authentication
- `core_videoguardado` - Saved favorite videos (models.py:5-18)
- `core_videosubido` - User-uploaded videos (models.py:21-36)
- Django admin and sessions

### Create Superuser

```bash
python manage.py createsuperuser
```

## 3. Static Files

```python
STATIC_ROOT = os.path.join(BASE_DIR, 'staticfiles')
```

Collect all static files:

```bash
python manage.py collectstatic --noinput
```

This creates the `staticfiles/` directory with all CSS, JavaScript, and images.

<Info>
The `staticfiles/` directory will contain Django admin assets and any custom static files from the `core` app.

</Note>

```python gunicorn_config.py (Production)
# Production-optimized Gunicorn configuration
import multiprocessing
```

### nginx Configuration

Create `/etc/nginx/sites-available/youtube_manager`:

<CodeGroup>

```nginx nginx (HTTP)
# HTTP configuration (for initial setup/testing)
server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;
    
    client_max_body_size 500M;  # Allow large video uploads
    
    # Static files (from settings.py:117)
    location /static/ {
        alias /path/to/your/project/staticfiles/;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
    
    # Media files (from settings.py:139)
    location /media/ {
        alias /path/to/your/project/media/;
        expires 7d;
    }
    
    # Proxy to Gunicorn
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_redirect off;
        
        # Timeout for video uploads
        proxy_read_timeout 300;
        proxy_connect_timeout 300;
        proxy_send_timeout 300;
    }
}
```

```nginx nginx (HTTPS)
# HTTPS configuration (production)
server {
    listen 80;
```

## 6. Process Management

### systemd Service

Create `/etc/systemd/system/youtube_manager.service`:

<CodeGroup>

```ini systemd (Basic)
[Unit]
Description=YouTube Manager Gunicorn Daemon
After=network.target mysql.service
Requires=mysql.service

[Service]
Type=notify
User=www-data
Group=www-data
RuntimeDirectory=gunicorn
WorkingDirectory=/path/to/your/project
Environment="PATH=/path/to/your/venv/bin"
EnvironmentFile=/path/to/your/project/.env
ExecStart=/path/to/your/venv/bin/gunicorn \
    --config /path/to/your/project/gunicorn_config.py \
    youtube_project.wsgi:application
ExecReload=/bin/kill -s HUP $MAINPID
KillMode=mixed
TimeoutStopSec=5
PrivateTmp=true

[Install]
WantedBy=multi-user.target
```

```ini systemd (Production)
[Unit]
Description=YouTube Manager Gunicorn Daemon
After=network.target mysql.service
Requires=mysql.service

[Service]
Type=notify
User=www-data
Group=www-data
RuntimeDirectory=gunicorn
WorkingDirectory=/path/to/your/project
Environment="PATH=/path/to/your/venv/bin"
EnvironmentFile=/path/to/your/project/.env

    --config /path/to/your/project/gunicorn_config.py \
    youtube_project.wsgi:application
ExecReload=/bin/kill -s HUP $MAINPID
KillMode=mixed
TimeoutStopSec=5
PrivateTmp=true
Restart=on-failure
RestartSec=5s

# Security hardening

PrivateDevices=true
ProtectSystem=strict
ProtectHome=true

[Install]
WantedBy=multi-user.target
```

## 9. Backup Strategy

### Database Backups

YouTube Manager stores critical user data in two main tables:

- **VideoGuardado** (`core_videoguardado`) - Saved favorite videos
- **VideoSubido** (`core_videosubido`) - User-uploaded video metadata

#### Automated MySQL Backup Script

Create `/usr/local/bin/backup_youtube_manager.sh`:

```bash backup_youtube_manager.sh
#!/bin/bash

# Configuration
DB_NAME="youtube_manager_prod"
DB_USER="youtube_user"
DB_PASS="your-password"
BACKUP_DIR="/var/backups/youtube_manager"
DATE=$(date +%Y%m%d_%H%M%S)
FILENAME="youtube_manager_${DATE}.sql.gz"
RETENTION_DAYS=30

# Create backup directory
mkdir -p $BACKUP_DIR

# Dump database
mysqldump -u $DB_USER -p$DB_PASS $DB_NAME | gzip > $BACKUP_DIR/$FILENAME

# Delete old backups
find $BACKUP_DIR -name "youtube_manager_*.sql.gz" -mtime +$RETENTION_DAYS -delete

echo "Backup completed: $FILENAME"
```

Make executable and set up cron:

```bash
sudo chmod +x /usr/local/bin/backup_youtube_manager.sh
sudo crontab -e
```

Add daily backup at 2 AM:

```cron
0 2 * * * /usr/local/bin/backup_youtube_manager.sh >> /var/log/youtube_manager/backup.log 2>&1
```

### Media Files Backup

<Info>
Media files in the `media/` directory are **temporary** - they're uploaded to YouTube and can be cleaned up. However, if you need to retain them:
</Info>

```bash
# Sync to remote storage (daily)
rsync -avz --delete /path/to/your/project/media/ user@backup-server:/backups/media/
```

Or use cloud storage:

```bash
# AWS S3
aws s3 sync /path/to/your/project/media/ s3://your-bucket/media/ --delete

# Google Cloud Storage
gsutil -m rsync -r -d /path/to/your/project/media/ gs://your-bucket/media/
```

## 10. Health Checks

### Application Health Endpoint

Create a simple health check view in `core/views.py`:

```python
from django.http import JsonResponse
from django.db import connection

def health_check(request):
    try:
        # Check database connection
        with connection.cursor() as cursor:
            cursor.execute("SELECT 1")
        
        return JsonResponse({
            'status': 'healthy',
            'database': 'connected'
        })
    except Exception as e:
        return JsonResponse({
            'status': 'unhealthy',
            'error': str(e)
        }, status=503)
```

Add to `urls.py`:

```python
path('health/', views.health_check, name='health_check'),
```

## Common Issues

### Static Files Not Loading

**Problem**: CSS/JS not loading, 404 errors

**Solution**:
```bash
# Ensure collectstatic was run
python manage.py collectstatic --noinput

# Check nginx configuration
sudo nginx -t

# Verify file permissions
ls -la /path/to/your/project/staticfiles/
```

### OAuth Redirect Mismatch

**Problem**: "redirect_uri_mismatch" error

**Solution**:
- Verify URLs in Google Cloud Console match exactly
- Ensure using HTTPS in production
- Check `ALLOWED_HOSTS` includes the domain

### 502 Bad Gateway

**Problem**: nginx returns 502 error

**Solution**:
```bash
# Check Gunicorn is running
sudo systemctl status youtube_manager

# Check Gunicorn logs
sudo tail -f /var/log/gunicorn/error.log

# Verify bind address matches nginx proxy_pass
```

### Database Connection Errors

**Problem**: "Can't connect to MySQL server"

**Solution**:
```bash
# Verify MySQL is running
sudo systemctl status mysql

# Test connection
mysql -u youtube_user -p youtube_manager_prod

# Check .env database credentials
```
